# CAAP: Capture-Aware Adversarial Patch Attacks on Palmprint Recognition

Official code repository for the paper:

**CAAP: Capture-Aware Adversarial Patch Attacks on Palmprint Recognition**

## Overview

This repository contains the implementation of **CAAP**, a capture-aware adversarial patch framework for palmprint recognition.

## Environment

Please create the environment from:

```bash
conda env create -f environment.yaml
conda activate caap
```

## Run

```bash
bash run_attack_train.sh
```

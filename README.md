# CAAP: Capture-Aware Adversarial Patch Attacks on Palmprint Recognition

Official code repository for the paper:

**CAAP: Capture-Aware Adversarial Patch Attacks on Palmprint Recognition**

## Overview

This repository contains the implementation of **CAAP**, a capture-aware adversarial patch framework for palmprint recognition.

## Environment

Please create the environment from:

```bash
conda env create -f environment.yaml
conda activate caap
```

## Data

The code uses aligned palmprint ROI images as input. Please prepare the datasets according to the experimental protocol described in the paper.

## Code

This repository will include:

- training code
- evaluation code
- transfer and ablation experiments
- physical attack evaluation
